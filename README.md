## Project Description

A real-time, rule-based **Network Intrusion Detection System** built entirely in Python.  
The system inspects every network packet against five detection rules and raises colour-coded alerts visible in a live web dashboard.

It runs in two modes:

| Mode | How to start | Requirement |
|---|---|---|
| **Simulation** | `python main.py --simulate` | None — works on any machine |
| **Live capture** | `python main.py -i Wi-Fi` | Npcap (Windows) or root (Linux/macOS) |

---

## Attack Types Detected

| # | Rule | Protocol | Detection Method | Threshold |
|---|---|---|---|---|
| 1 | SYN Flood | TCP | Sliding-window counter | > 100 SYN/5 s |
| 2 | Port Scan | TCP/UDP | Distinct-port sliding window | > 15 ports/5 s |
| 3 | ICMP Flood | ICMP | Sliding-window counter | > 50 pkts/5 s |
| 4 | Null Scan | TCP | Per-packet flag check | flags == 0x00 |
| 5 | Xmas Scan | TCP | Per-packet flag check | FIN+PSH+URG |

## Setup & Run Instructions

### 1. Clone / download the project

```bash
cd nids_project
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. (Windows — live mode only) Install Npcap

Download and install Npcap from <https://npcap.com>.  
**Not required for simulation mode.**

### 4. Run the application

```bash
# Simulation mode (recommended for testing — no driver needed)
python main.py --simulate

# Live capture on the default Wi-Fi interface
python main.py -i Wi-Fi

# Live capture on a custom interface, custom port
python main.py -i Ethernet --port 8080
```

### 5. Open the dashboard

Navigate to **http://127.0.0.1:5000** in your browser.

The dashboard auto-refreshes every 5 seconds and shows:
- Live alert count by type (SYN Flood, Port Scan, ICMP Flood, Other)
- Full alert table (timestamp, type, source IP, destination IP, detail)
- Stop / Resume sniffer controls
- Clear alerts button

### 6. Run the smoke test (optional)

```bash
python _smoketest.py
```

Runs the simulator for 15 seconds and prints alert counts. Expected output: `PASS`.

## Dataset / Traffic Source

This project does **not** use an external dataset.  
- **Simulation mode:** Synthetic traffic is generated by the built-in `_simulate()` function in [`nids/sniffer.py`](nids/sniffer.py) using 6 attacker IPs, 3 victim IPs, and realistic attack burst patterns.  
- **Live mode:** Real packets captured from the host NIC via Scapy.

## Dashboard REST API

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | HTML dashboard |
| GET | `/api/alerts` | All alerts as JSON |
| POST | `/api/alerts/clear` | Clear all alerts |
| GET | `/api/status` | Sniffer running state |
| POST | `/api/stop` | Pause sniffer |
| POST | `/api/resume` | Resume sniffer |
